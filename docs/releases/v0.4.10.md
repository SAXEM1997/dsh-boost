本版只改发版说明的写法：从这一版起，发版说明是一份变更清单——开头一段总结陈述事实与范围，随后每个 pull request 一行，机制、根因与实测数据一律留在 PR 和 issue 里，不写进正文。此前 0.4.7–0.4.9 三版按诊断报告写，已发布的内容不做改写，所以这四版在 GitHub 上会看到两种写法。插件本身没有改动：投影、替换、蒸馏、设置页与发布流水线的行为与本版之前完全一致。

**中文**

- 发版说明改为「一个 PR 一行」的变更清单格式，规则写入 `AGENTS.md` 与 `docs/RELEASE.md` §6.0，机械可查的部分由测试钉住（#24）。

**English**

From this version on, release notes are a change list: a summary paragraph, then one line per pull request, with mechanism and measurements left to the PR and the issue. The 0.4.7–0.4.9 bodies were written as diagnosis reports and are left as published. No runtime changes.

- Release notes follow the one-line-per-PR change-list format; the rule lives in `AGENTS.md` and `docs/RELEASE.md` §6.0, and its mechanically checkable part is pinned by a test (#24).
