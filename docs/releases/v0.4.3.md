**English**

Two-axis review fixes (Standards and Spec) over 0.3.14 → 0.4.2. Two of them are mistakes I introduced inside 0.4.x.

- One fact copied three times, only one copy updated: "`boost` is the sole scope exemption / always resident / `selected + []` really costs 399" appeared in `operating.md` and `how-it-works.md` as well, and 0.4 changed visibility without touching them — both then contradicted the code. Each axis found this independently.
- Version attribution wrecked a second time: bumping the version meant a blanket `0.4.1` → `0.4.2` replacement in the docs, which rewrote what 0.4.1 had shipped. Restored sentence by sentence from the CHANGELOG; the version list regained 0.3.13/0.3.14/0.4.0.
- Two tests could not catch their own regressions: making the visibility predicate "hidden once judged" stayed green, and turning `continuation`'s `every` into `some` stayed green. Both now have cases.
- Removed `duplicates.duplicateResultChars`: it paired receipts by arrival order, so parallel calls computed the wrong total, and nothing read it.
