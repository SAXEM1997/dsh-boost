**中文**

A/B 跑法（`docs/quality-runbook.md`）、它需要的最后一块机械动作，以及两轴评审对 0.4.2/0.4.3 的复审修复。

- 跑法七步落地：冻结 commit/版本/工作区、产任务表、基线臂 `projection: off`、处理臂 `on`（两臂都 `shadow:false`）、比较、预先定死的判据、结果文件格式；另附「七个会毁掉实验的错」。
- 修正一处会静默废掉整个实验的错误：runbook 让人从 `boost status` 取 `data.usage.totalTokens`，该字段不存在，照做两臂 token 恒 778、`tokenDelta` 恒 0。改从 `session-stats.mjs --sessions` 取。
- `quality-tasks.mjs` 增加 `task` 字段（会话首条用户消息，截 400 字符）——没有任务陈述就没法重放。
- `isFinal` 改为按全部工具调用判定：此前只看带 `command` 的调用，验证命令后跟一条 `read` 仍判「已验证」。
- 又两处 0.3 的「399」，`--min-pairs 0` 不是门（改为要求正整数），判据符号写反（`tokenDelta` 应小于 0），结果文件从一份改成三份。

**English**

The A/B procedure (`docs/quality-runbook.md`), the last mechanical piece it needed, and the two-axis review fixes over 0.4.2/0.4.3.

- Seven-step procedure: freeze commit/version/workspace, produce the task table, baseline arm with `projection: off`, treatment arm with `on` (both `shadow:false`), compare, apply the criterion fixed in advance, and the result-file format — plus "seven mistakes that will ruin the experiment".
- Fixed one error that would silently void the whole experiment: the runbook told operators to read `data.usage.totalTokens` from `boost status`, a field that does not exist, which would have pinned both arms at 778 and `tokenDelta` at 0. Now read from `session-stats.mjs --sessions`.
- `quality-tasks.mjs` gains a `task` field (the session's first user message, 400 chars) — without the task statement nothing is replayable.
- `isFinal` now judges on all tool calls: it used to look only at calls carrying `command`, so a `read` after the verification command still read as "verified".
- Two more 0.3-era "399" leftovers; `--min-pairs 0` was not a gate (now a positive integer is required); the criterion had its sign inverted (`tokenDelta` must be below 0); the result file went from one to three.
