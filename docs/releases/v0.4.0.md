**中文**

`boost` 工具不再无条件注入，与协议段共用同一个可见性判定：本会话的工作区不在作用域内时，工具 schema 也不下发。固定开销因此变成上界——可见 778 token，不可见 0。

- `boost` 工具改为按作用域隐藏，作用域外的会话不再每请求白付 399 token 的 schema 开销。
- `fixedOverheadTokens` 改按上界语义报告（778 / 0），status 与文档同步。
- 启用文档改为 page-first：先装、再开设置页、最后按工作区授权。
- 已知代价：失去「对话里直接 `boost scope-set` 把自己拉进作用域」的 bootstrap 路径，需在页面或配置文件里完成首次授权。

**English**

The `boost` tool is no longer injected unconditionally; it shares one visibility decision with the protocol section. When the session's workspace is out of scope, the tool schema is not sent either. Fixed overhead therefore becomes an upper bound — 778 tokens when visible, 0 when not.

- `boost` is now hidden outside scope, so out-of-scope sessions stop paying 399 tokens of schema per request.
- `fixedOverheadTokens` reports an upper bound (778 / 0); status output and docs follow.
- Enablement docs are now page-first: install, open the settings page, then authorise workspaces.
- Known cost: the in-conversation bootstrap (`boost scope-set` pulling yourself into scope) is gone; the first authorisation happens in the page or the config file.
